# Current Constraint Capabilities

## Purpose

This document summarizes the existing constraint validation capabilities before and during CSV pipeline integration.

---

## Existing Constraint Types

Supported by:

```text
data_processor/validators/constraints.py
```

Current constraint types:

```text
required
unique
min_value
max_value
allowed_values
regex_pattern
```

---

## Validation Results

Validation returns `ValidationResult` objects with:

```text
column_name
constraint_type
passed
message
row_index
value
```

---

## Validation Report

Generated by:

```text
data_processor/validators/validation_report.py
```

Report fields:

```text
total_results
passed_count
failed_count
has_failures
failures_by_column
failures_by_constraint
failed_rows
failed_results
```

---

## Integration Gap Before This Plan

Before this plan, constraints existed but were not directly accepted by the CSV pipeline.

The diagnostic bundle had a validation report section, but the normal pipeline passed no user-provided validation results.

---

## Design Rule

Validators validate only.

They must not clean, cast, quarantine, or export data.
