# diagnostic_bundle.py

## Purpose

`diagnostic_bundle.py` creates one complete diagnostic report from a processed `Table`.

It belongs to the report layer and aggregates existing diagnostic sections without modifying data.

---

## Architecture

```text
Table + Validation Results
→ Diagnostic Bundle
→ Complete Report Dictionary
```

---

## Main Function

### `build_diagnostic_bundle(table, validation_results=None)`

Returns a dictionary with these top-level sections:

```python
{
    "table_name": "...",
    "row_count": ...,
    "column_count": ...,
    "metadata": {...},
    "parse_diagnostics": {...},
    "quality_report": {...},
    "column_profiles": {...},
    "row_profiles": [...],
    "validation_report": {...}
}
```

---

## `metadata`

Contains metadata stored on the table.

For CSV input, this can include:

```text
source_format
encoding
delimiter
header_row_index
preamble_rows
parse_diagnostics
```

---

## `parse_diagnostics`

Copied from:

```python
table.metadata.get("parse_diagnostics", {})
```

This section describes source parsing observations such as:

- rows with extra fields
- rows with missing fields
- duplicate headers
- empty headers
- detected delimiter
- detected encoding
- parser warnings

If no parser diagnostics are available, the section is an empty dictionary.

---

## `quality_report`

Generated by:

```python
generate_quality_report(table)
```

Includes missing values, duplicate rows, empty columns, and high-null columns.

---

## `column_profiles`

Generated by:

```python
profile_all_columns(table)
```

Includes column-level profile data.

---

## `row_profiles`

Generated by:

```python
profile_all_rows(table)
```

Includes row-level profile data.

---

## `validation_report`

Generated by:

```python
generate_validation_report(validation_results)
```

If no validation results are provided, the validation report is included but empty.

---

## Design Rules

Diagnostic bundles aggregate reports only.

They must not:

- clean data
- cast values
- validate constraints directly
- modify rows
- export files

Exporting belongs to report exporters.

---

## Developer Notes

This module should stay small and avoid duplicating report logic.

Future additions may include timestamps, runtime duration, report versioning, source metadata, and quality scoring.
