# diagnostic_bundle.py

## Purpose

`diagnostic_bundle.py` creates one complete diagnostic report from a processed table.

This module belongs to the report layer.

Architecture:

```text
Table + Validation Results
→ Diagnostic Bundle
→ Complete Report Dictionary
```

---

# Why This Module Exists

The project now has multiple diagnostic systems:

```text
quality_report
column_profiles
row_profiles
validation_report
```

Each is useful separately, but real migration workflows need one combined report.

This module creates that combined report.

---

# Main Function

## `build_diagnostic_bundle(table, validation_results=None)`

Builds a complete diagnostic report.

Returns:

```python
{
    "table_name": "...",
    "row_count": ...,
    "column_count": ...,
    "quality_report": {...},
    "column_profiles": {...},
    "row_profiles": [...],
    "validation_report": {...}
}
```

---

# Included Sections

## `table_name`

Name of the internal table.

Usually derived from the source file name.

---

## `row_count`

Total number of rows.

---

## `column_count`

Total number of schema columns.

---

## `quality_report`

Generated by:

```python
generate_quality_report(table)
```

Includes:

- missing values
- duplicate rows
- empty columns
- high-null columns

---

## `column_profiles`

Generated by:

```python
profile_all_columns(table)
```

Includes:

- missing ratio
- unique ratio
- sample values
- common values
- numeric min/max

---

## `row_profiles`

Generated by:

```python
profile_all_rows(table)
```

Includes:

- row-level missing count
- row-level missing ratio
- empty row detection
- duplicate candidate detection

---

## `validation_report`

Generated by:

```python
generate_validation_report(validation_results)
```

Includes:

- passed count
- failed count
- failures by column
- failures by constraint
- failed rows

If no validation results are provided, the validation report is still included but empty.

---

# Example Usage

```python
from data_processor.reports.diagnostic_bundle import build_diagnostic_bundle

bundle = build_diagnostic_bundle(
    table=table,
    validation_results=validation_results,
)
```

# Important Design Rule

Diagnostic bundles aggregate reports only.

They must not:

- clean data
- cast values
- validate constraints directly
- modify rows
- export files

Exporting belongs to report exporters.

---

# Pipeline Position

Recommended workflow:

```text
Parse
→ Clean
→ Infer Types
→ Type Casting
→ Schema Metadata
→ Constraint Validation
→ Diagnostic Bundle
→ Report Export
→ Data Export
```
