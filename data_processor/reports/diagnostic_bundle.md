# diagnostic_bundle.py

## Purpose

`diagnostic_bundle.py` creates one complete diagnostic report from a processed `Table`.

It belongs to the report layer and aggregates existing diagnostic sections without modifying data.

---

## Architecture

```text
Table + Validation Results
→ Diagnostic Bundle
→ Complete Report Dictionary
```

---

## Main Function

### `build_diagnostic_bundle(table, validation_results=None)`

Returns a dictionary with these top-level sections:

```python
{
    "table_name": "...",
    "row_count": ...,
    "column_count": ...,
    "metadata": {...},
    "parse_diagnostics": {...},
    "quality_report": {...},
    "column_profiles": {...},
    "row_profiles": [...],
    "type_diagnostics": {...},
    "validation_report": {...}
}
```

---

## `parse_diagnostics`

Describes source parsing observations such as short rows, extra fields, duplicate headers, empty headers, detected delimiter, and detected encoding.

---

## `quality_report`

Includes missing values, duplicate rows, empty columns, and high-null columns.

---

## `column_profiles`

Includes column-level profile data.

---

## `row_profiles`

Includes row-level profile data.

---

## `type_diagnostics`

Generated by:

```python
analyze_table_type_evidence(table)
```

Includes:

```text
columns
mixed_type_columns
```

This section reports mostly consistent columns that contain incompatible values.

Example:

```python
{
    "mixed_type_columns": [
        {
            "column": "amount",
            "dominant_type": "float",
            "invalid_values": [
                {
                    "row_index": 2,
                    "value": "unknown",
                    "expected_type": "float"
                }
            ]
        }
    ]
}
```

---

## `validation_report`

Generated by:

```python
generate_validation_report(validation_results)
```

If no validation results are provided, the validation report is included but empty.

---

## Design Rules

Diagnostic bundles aggregate reports only.

They must not:

- clean data
- cast values
- validate constraints directly
- modify rows
- export files

Exporting belongs to report exporters.

---

## Developer Notes

This module should stay small and avoid duplicating report logic.

Future additions may include timestamps, runtime duration, report versioning, source metadata, and quality scoring.
